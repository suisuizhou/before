# 716

## 1. 文档定位

本文档整理截至 2026-07-16 在 PU4D 四域数据集上得到的当前最佳 TTA 方法。当前以严格在线 Accuracy 为主指标时，最优方法为 `BN-first Full`；其 0→1 结果为 45.0964% Accuracy 和 44.3556% Macro-F1。

需要明确：`BN-first Full` 仅以 Accuracy 领先。`BN-MT-Adapter` 的 Macro-F1 为 44.3786%，比 Full 高 0.0230 个百分点；Full 的 Accuracy 只比它高 0.0212 个百分点。因此两者在当前单任务上的性能基本持平，不能把 Full 的额外模块解释为已获得显著收益。

本文档描述已经实现并完成实验的版本，不包含尚未实现的源类原型补全、全局频率尺度模块或目标标签驱动调参。

### 2.2 消融结果

| 方法 | 核心变化 | Accuracy | Macro-F1 |
|---|---|---:|---:|
| Source-only | 冻结源模型 | 18.33% | 未记录 |
| 旧 Full EVMT | 旧 0711 实现 | 20.72% | 未记录 |
| BN-stat | 仅严格滞后目标 BN 统计 | 41.5386% | 40.7889% |
| BN-affine | BN-stat + BN affine + SEM | 45.0720% | 44.2707% |
| BN-MT-Adapter | 再加入 Adapter、Warp 和 MT | 45.0751% | **44.3786%** |
| BN-first Full | 再加入 Evidence、Memory、PCL、NCL | **45.0964%** | 44.3556% |

从消融结果可得：

1. 严格滞后 BN 统计带来最大增益，Accuracy 从 18.33% 提升到 41.54%。
2. BN affine 继续提升约 3.53 个百分点，是第二个关键组件。
3. MT、Adapter 和 Warp 在本任务上的额外 Accuracy 增益只有约 0.003 个百分点。
4. Evidence、Memory、PCL 和 NCL 将 Accuracy 再提高约 0.021 个百分点，但 Macro-F1 略有下降。

## 3. 方法目标与约束

BN-first Full 的目标是在不重新训练源模型、不访问目标标注进行适配的前提下，优先修复跨域时的 BN 统计偏移，再以轻量参数和可靠性控制完成在线自适应。

固定约束如下：

- 基础模型固定为 `ResNet18_1D_SDE`，不使用 ViT1D。
- 数据集固定为 PU4D 四域版本，共 32 类；旧三域 PU 不参与本实验。
- 目标数据严格单遍，当前 Batch 不允许影响自身计分。
- 目标标签只用于离线计算 Accuracy 和 Macro-F1，不参与梯度、BN 统计、伪标签、可靠性、阶段切换、崩塌保护或参数选择。
- 每个 Batch 至多执行一次 Student 参数更新。
- 不更新卷积权重、非 BN bottleneck 参数和分类器权重。

## 4. 严格在线数据流

对第 `t` 个目标 Batch，执行顺序为：

1. 使用源 BN 统计与目标 Batch `1..t-1` 的历史矩融合结果，对当前 Batch 进行计分。
2. 立即保存更新前 logits、预测类别和在线指标。
3. 在不读取标签的情况下提取当前 Batch 的各层 BN 输入矩，并合并到目标历史状态。
4. 使用包含当前 Batch 历史矩的融合 BN 状态，重新计算 Student、Teacher 多视图和无监督损失。
5. 运行崩塌保护和有限值检查。
6. 若检查通过，执行一次 Student 更新；在允许的阶段写入目标记忆并更新 Teacher EMA。
7. 丢弃当前 Batch，不再访问。

第一批只能使用源 BN 统计。诊断实验中使用“当前 Batch BN 统计直接预测当前 Batch”得到的 42.21% 只用于证明 BN 偏移，不属于正式严格在线结果。

## 5. BN-first Full 组成

### 5.1 严格滞后目标 BN 统计

`TargetBNController` 保存不可变源 `running_mean/running_var`，并为每个 BN 层维护累计目标均值、二阶中心矩和样本数。目标统计采用按样本数加权的并行矩合并，而不是平均各 Batch 方差。

预测时使用源统计与历史目标统计的总方差融合：

```text
mix_mean = (1-w) * source_mean + w * target_mean
mix_var  = (1-w) * [source_var + (source_mean-mix_mean)^2]
         + w * [target_var + (target_mean-mix_mean)^2]
```

目标权重 `w` 在前 5 个 Batch 从 0 线性增加到 0.9，融合方差下限为 `1e-5`。Student 和 Teacher 使用同一套控制器状态，BN running statistics 不进入梯度或 EMA。

### 5.2 可训练参数

Student 只训练：

- 所有 BN 层的 `weight` 和 `bias`；
- 频谱 Adapter 的 `band_scale`、`band_bias`；
- 局部频率 Warp 的 `warp_ctrl`。

学习率相对目标基础学习率的比例为：

| 参数组 | 学习率比例 |
|---|---:|
| BN affine | 0.1 |
| Adapter | 1.0 |
| Warp | 0.2 |

Teacher 仅对上述参数执行 EMA，`ema_beta=0.99`。BN running statistics 由 `TargetBNController` 独立管理。

### 5.3 Teacher 多视图与可靠性

Teacher 使用三个标签保持视图：

- 原始目标输入；
- 低强度频谱风格扰动；
- 小幅平滑频率轴 Warp。

Teacher 概率取三个视图预测的均值。基础可靠性由熵置信度和视图一致性构成；进入证据阶段后，再乘以破坏性证据得分。

破坏性证据流程为：计算伪标签对应 logit 对输入频带的显著性，选择连续高显著频带，用局部中值替换这些频带，再测量原伪标签的分类 margin drop。只有同时满足置信度、视图 JS、正 margin drop 和类内/全局可靠性阈值的样本才标记为 certain。

### 5.4 类平衡目标记忆

记忆库按伪类别建立 FIFO 队列，每类最多保存 32 个 certain 目标特征。条目包含归一化 Teacher 特征、软概率、可靠性和写入步数。

记忆库只使用目标伪标签和无标签可靠性条件，不读取真实目标标签。PCL 使用类内可靠性加权原型；NCL 使用目标记忆中的近邻软分布。

### 5.5 三阶段状态机

#### 阶段 A：`bn_warmup`

- 至少运行 20 个 Batch；
- 启用 BN 统计、BN affine、Adapter/Warp、SEM 和 MT；
- 可靠性只使用置信度与多视图一致性；
- 不计算破坏性证据，不写记忆，不启用 PCL/NCL。

#### 阶段 B：`evidence_build`

当 `step > 20` 且最近 5 个 Batch 的预测类别联合覆盖不少于 24/32 时进入：

- 启用破坏性证据和 certain 路由；
- 开始写入类平衡目标记忆；
- PCL/NCL 仍关闭。

#### 阶段 C：`full`

当记忆覆盖不少于 16 个类别，且每个已使用类别至少有 2 个目标条目时进入：

- certain 样本启用 PCL；
- uncertain 样本启用 NCL；
- 继续使用 SEM、MT、Evidence 和参数正则。

阶段只能单向推进，条件不足时不会强制进入 Full。本次 0→1 实验实际运行 20 个 warm-up Batch、2 个 evidence-build Batch 和 292 个 full Batch。

## 6. 优化目标

阶段 A/B 的总损失为：

```text
L_A/B = L_SEM + lambda_mt * L_MT
      + lambda_bn * L_BN-anchor
      + lambda_reg * L_Adapter
      + lambda_warp * L_Warp
```

阶段 C 的总损失为：

```text
L_Full = L_A/B + lambda_pcl * L_PCL + lambda_ncl * L_NCL
```

关键权重如下：

| 参数 | 数值 |
|---|---:|
| `lambda_mt` | 0.5 |
| `lambda_pcl` | 0.2 |
| `lambda_ncl` | 0.2 |
| `lambda_bn` | 0.001 |
| `lambda_reg` | 0.001 |
| `lambda_warp` | 0.0002 |
| PCL temperature `tau` | 0.1 |
| 邻居数 `neighbor_k` | 5 |
| 梯度裁剪 | 5.0 |

`L_BN-anchor` 约束 BN affine 不快速偏离源参数；Adapter 正则约束实际频带 scale/bias 接近恒等映射；Warp 正则同时约束位移幅度和一阶平滑性。

## 7. 崩塌保护

每个计分 Batch 计算预测边际分布及以下无标签指标：

- 有效类别数 `exp(H(mean_p))`；
- 最大类别概率占比；
- 相对稳定参考的有效类别下降比例；
- logits、loss 和梯度有限性。

满足任一条件时跳过梯度更新、记忆写入和 Teacher EMA：

- 有效类别数低于 8；
- 最大类别占比超过 0.5；
- 有效类别数相对稳定参考下降超过 50%；
- logits、loss 或梯度出现 NaN/Inf。

本次 Full 实验 314 个 Batch 均通过保护检查，跳过数为 0。

## 11. 当前判断与后续边界

当前可以确认：

- BN mismatch 是 0→1 的首要瓶颈；
- 严格滞后 BN 统计和 BN affine 已取得稳定、可复现的大幅提升；
- Full 的额外 Evidence/PCL/NCL 在 0→1 上尚未表现出显著优势；
- 当前最佳 Accuracy 为 45.0964%，但不能仅凭一个任务断言 Full 普遍优于 BN-MT-Adapter。

下一步应保持本文件中的阈值和学习率不变，在第二个代表性任务 0→2 上运行相同消融矩阵。只有两个任务均稳定后，才决定冻结 `BN-first Full` 或更精简的 `BN-MT-Adapter`，并进一步运行全部 12 个四域迁移任务。
