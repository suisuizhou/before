# PU4D 上的 EVMT-DtCC：设计与实验规格

## 1. 目标与范围

在四域 PU4D 数据集上实现并评估 `idea/方案0711.md`。基础模型采用 `ResNet18_1D_SDE`，结合 EMA 多视图教师、基于干预的频谱证据验证、可靠性感知路由和 DtCC 风格的 PCL/NCL。

先在 0→1、0→2 上调试和校准，配置冻结后扩展到全部 12 个有向任务。旧三域 PU 和 ViT1D 不在范围内。0711方案具有最高优先级；仅当其假设缺少 PU4D 元数据支持、与严格在线协议冲突或造成可确认的稳定性故障时才调整，并在实验日志中说明原因。

## 2. 数据集与在线协议

PU4D 含 32 个轴承类别和四个域：

- 域0：`D1_1500_0.7_1000`
- 域1：`D2_900_0.7_1000`
- 域2：`D3_1500_0.1_1000`
- 域3：`D4_1500_0.7_400`

固定 0→1（转速变化）和 0→2（径向载荷变化）为校准任务。二者单独报告；其余10个任务作为主要泛化汇总，同时报告12任务总汇总。

采用严格单遍在线协议：每个目标 batch 先预测并计入在线指标，再仅用该无标签 batch 更新一次，之后进入下一个未见 batch。目标样本不得重访。适配后的全目标集准确率仅作诊断。目标标签不得参与适配、阈值选择、早停、回滚或超参数选择，只能在预测后用于指标和离线分析。

## 3. 源模型重训

使用带线性分类器的 `ResNet18_1D_SDE`，按当前 `main_Src_SDE.py` 的 SDE 增强配方重训，包括 SSP 风格增强、频率 warp、一致性目标、特征一致性、标签平滑和 mixup。不复用旧检查点。

源模型只能依赖源域。每个随机种子训练4个源模型（每个源域一个），每个检查点复用于从该源域出发的三个目标任务，且只按源域准确率选择。校准先用一个固定种子；正式12任务使用三个固定种子，报告均值和标准差。记录完整配置、最佳 epoch、源准确率、仅作诊断的目标准确率、路径和检查点哈希。

## 4. 架构与模块边界

保留 `main_Src_SDE.py` 和 `main_tta_SDE.py` 作为基线。新方法使用独立入口，并拆分为：

1. 多视图教师：生成标签保持视图并聚合预测。
2. 证据验证器：生成标签破坏视图，计算 PLPD 和 margin drop。
3. 可靠性路由器：融合置信度、视图一致性与证据，生成 certain/uncertain 掩码。
4. 类别均衡记忆库：保存已验证的教师特征和软标签，计算类别原型。
5. 适配损失：计算加权 SEM、PCL、NCL、均值教师蒸馏和正则项。
6. 在线运行器：保证先预测后更新，管理 Student/Teacher 和日志。

Student 与 Teacher 从同一新源检查点初始化。TTA 冻结卷积 backbone、bottleneck、classifier 和归一化仿射参数，只训练 `band_scale`、`band_bias`、`warp_ctrl`。ResNet18 没有 prompt，因此移除 prompt 分支。Teacher 维护可适配状态的 EMA 副本；固定权重逻辑共享，adapter/warp 状态独立，教师输出全部停止梯度。

## 5. 单个 batch 的数据流

1. Student 用更新前状态预测并计分。
2. Teacher 对原始 FFT、弱 SSP 幅值风格扰动、弱频率 warp 预测。
3. 平均三组概率，得到软标签 `q` 和伪标签。
4. 计算归一化熵置信度 `c` 与 JS 视图一致性 `a`。
5. 构造频谱证据掩码和破坏视图，根据预测变化得到证据 `e`。
6. 计算 `r = c × a × e`，划分 certain/uncertain。
7. warm-up 只运行低权重可靠性 SEM 与均值教师；记忆满足条件后启用 PCL/NCL。
8. 检查有限值，反向一次、裁剪梯度并更新 Student adapter/warp。
9. Student 更新后，将通过检查的更新前 Teacher 特征写入记忆，避免样本成为自己的历史近邻。
10. EMA 更新 Teacher，进入下一 batch。

## 6. 多视图教师

首版固定三视图以控制开销。两种弱扰动沿用源 SDE 的变换类型但降低强度，并必须保持类别。破坏性证据视图绝不能进入平均。

教师软标签是三视图概率均值。置信度为 1 减去以 `log(C)` 归一化的熵；各视图与均值预测的 Jensen-Shannon 散度经指数衰减转为一致性。所有可靠性输入停止梯度。

## 7. 频谱证据验证

当前 PU4D 接口没有足够可靠的逐样本轴承几何、故障特征频率和边带元数据，首版采用0711中的 Teacher 显著性方案，不将其宣称为物理先验掩码。

对预测类别计算平滑后的 `|x × ∂logit/∂x|`，选择少量连续高响应频带，以局部中位数背景替换，避免置零产生人为突变。记录普通 PLPD，以类别 margin drop 为主证据分数。高分只表示模型依赖被移除区域，不能单独证明伪标签正确，必须联合置信度和视图一致性。随机频带遮挡只作消融。

## 8. 可靠性与路由

证据分数按 batch median/MAD 稳健归一化并映射到 `[0,1]`；MAD 退化时回退到停止梯度的滑动稳健统计。最终 `r = confidence × view_agreement × normalized_evidence`。

certain 样本必须通过最低置信度、最大视图分歧和正 margin drop 三个绝对门槛。通过门槛后再做类别均衡路由：类内支持足够时用类内阈值，否则用 batch 全局阈值，防止 singleton 自动成为 certain。阈值与最小支持只在两个校准任务上确定，随后冻结；标签不参与路由。

## 9. Warm-up 与记忆库

满足最小 batch 数和类别覆盖后结束 warm-up；若一直不满足，则在最大 warm-up 长度处结束。其间只有通过绝对门槛的样本可入库，PCL/NCL 在各自条件满足前关闭。

每个预测类维护固定容量 FIFO 队列，条目包含更新前 Teacher 特征、软标签、伪标签、可靠性和写入步数。只有 certain 样本可写入。原型为已存归一化特征的可靠性加权均值。记忆全部停止梯度；记录容量、覆盖率和年龄分布。真实标签只离线计算诊断性的记忆纯度。

## 10. 适配目标

总损失：

`L = L_SEM^r + λp L_PCL + λn L_NCL + λm L_MT + λreg L_adapter + λwarp L_warp`

- `L_SEM^r`：可靠性加权 Tsallis entropy 加 batch diversity；权重为 `η+(1-η)r`，`η>0`。
- `L_PCL`：仅作用于有正原型的 certain 样本；正原型不存在时跳过。
- `L_NCL`：仅作用于 uncertain 样本，以历史近邻的正余弦相似度和可靠性形成停止梯度软目标；近邻不足时跳过。
- `L_MT`：将 Teacher 多视图软预测蒸馏到 Student clean 预测，并按可靠性加权。
- adapter/warp 正则约束变形幅度。

DeYO 证据不是额外损失，只控制路由、记忆准入以及 SEM/蒸馏权重。

## 11. 稳定性与异常处理

adapter 与 warp 使用独立参数组，warp 学习率倍率更低；执行梯度裁剪并检查损失、梯度和新参数是否有限。出现 NaN/Inf 时跳过优化、记忆写入和 Teacher EMA，并记录异常。

无标签塌缩保护只依据预测多样性或有效类别数的灾难性变化跳过更新，准确率绝不参与。必须正确处理原型不存在、certain/uncertain 为空、近邻不足、MAD 退化和末 batch 单样本，不得伪造样本，并记录所有跳过分支。

## 12. 实验矩阵

所有方法共享新源检查点、目标顺序、batch size、种子和严格在线协议：

1. Source-only。
2. 严格在线 SEM/F-Warp。
3. MT：多视图 EMA Teacher 加可靠性 SEM。
4. MT+Evidence：加入证据与路由，不启用 PCL/NCL。
5. 完整 EVMT-DtCC。

校准任务消融包括：无 evidence、随机遮挡替代显著性、无类别均衡、无 warm-up、无 PCL、无 NCL。参数冻结后，在12任务、三个种子上运行 Source-only、严格在线基线和 Full。核心实验完成后才扩展更多全任务消融。

## 13. 指标与验收

主要指标为更新前在线准确率和 macro-F1。报告逐任务、校准2任务均值、其余10任务均值、12任务均值、三种子标准差和最差任务；同时报告耗时、显存、certain 比例、预测类别覆盖和记忆覆盖。

工程验收要求：

- EMA、可靠性/路由、记忆容量、损失边界和先预测后更新顺序有单元测试。
- CPU/小规模冒烟测试无 NaN/Inf。
- 两个校准任务均完成严格在线运行。
- 相同种子配置可复现。

方法成功标准为 Full 的平均在线准确率同时高于新 Source-only 和严格在线基线，且提升不只来自少数任务。未达标仍须如实报告；修改0711前，先检查 evidence-正确性相关性、伪标签准确率、记忆纯度、路由覆盖和塌缩指标。

## 14. 日志与复现

每次运行建立唯一目录，保存完整配置与命令、Git commit/dirty 状态、Python/PyTorch/CUDA/GPU 环境、数据标识与样本数、种子、源检查点哈希、batch 级 JSONL、任务/种子级 CSV 和控制台日志。

batch 指标包括更新前准确率、各损失、置信度、视图分歧、PLPD、margin drop、可靠性、certain 比例、类别分布、记忆占用、梯度与 adapter/warp 范数、跳过分支、塌缩保护和耗时。

另建按日期维护的中文实验日志，记录操作、偏离0711的理由、命令、结果、失败和下一步。所有使用目标标签的证据相关性和记忆纯度须标记“仅离线分析”。
