# PU4D BN-first EVMT 改进设计

## 1. 背景与诊断结论

当前 `0→1` 严格单遍在线实验使用 `ResNet18_1D_SDE`，Source-only 准确率为 18.33%，完整 EVMT 为 20.72%。现有方法虽然获得 2.39 个百分点的正增益，但绝对准确率明显不足。

离线诊断只使用目标标签计算指标，不让标签参与适配。保持检查点、数据和模型结构不变，仅将冻结的源域 BN 统计替换为目标 batch 统计后，准确率从 18.33% 提升到 42.21%，预测类别覆盖从 31/32 恢复到 32/32。冻结 BN 时模型将 47,834 个样本预测为类别2，并且从不预测类别6，说明首要瓶颈是源域 BN 统计与目标域分布不匹配，而不是0711方案缺少更多损失。

当前实现还存在以下已确认缺口：

- 只训练 `band_scale`、`band_bias`、`warp_ctrl`，没有使用 DtCC 中关键的 BN 适配。
- PCL/NCL 固定从第6个 batch 启用，没有等待预测类别和记忆库覆盖充分。
- `lambda_reg`、`lambda_warp` 已配置但尚未进入总损失。
- 缺少预测类别塌缩保护、记忆覆盖日志和参数变化日志。
- `use_evidence` 开关没有完整控制证据分支，消融口径不可靠。

本设计优先修复上述问题。源模型重训和全局转速尺度对齐属于后续阶段，不与本轮修改混合，以便确定收益来源。

## 2. 目标与非目标

### 2.1 目标

1. 在不重训源模型的前提下实现严格在线、滞后一批的目标 BN 统计适配。
2. 将 BN 仿射参数加入轻量可训练状态，同时保留 Adapter 和局部 Warp。
3. 将0711的 warm-up、证据路由、记忆准入和 PCL/NCL 启用条件改为状态驱动。
4. 补齐 Adapter/Warp 正则、塌缩保护和可复现实验日志。
5. 先在 `0→1` 上完成单变量消融；稳定后再以相同冻结配置运行 `0→2`。

### 2.2 非目标

- 本轮不重新训练源模型。
- 本轮不加入基于转速元数据的全局频率尺度模块。
- 本轮不运行全部12个任务。
- 本轮不改变32类标签映射、PU4D缓存或 ResNet18 主干结构。
- 目标标签不得参与梯度、BN统计、路由、阈值、回滚或参数选择。

## 3. 严格在线协议

对于第 `t` 个目标 batch，必须按以下顺序执行：

1. 使用只包含源统计和 `1..t-1` 历史目标统计的 BN 状态预测当前 batch。
2. 立即保存更新前 logits、预测类别和在线指标；当前 batch 的统计量不能影响该次计分。
3. 在不使用标签的情况下计算当前 batch 的 BN 均值与方差，更新历史目标统计。
4. 使用更新后的适配态计算 Teacher 多视图、证据、路由和无监督损失。
5. 执行至多一次 Student 梯度更新；更新只影响后续 batch。
6. 通过保护检查后写入记忆库并更新 Teacher EMA。
7. 当前 batch 永不重访。

第一批只能使用源 BN 统计。该协议与使用当前 batch 统计直接预测的42.21%诊断上限不同，后者只用于证明 BN 偏移，不作为正式结果。

## 4. 模块设计

### 4.1 `TargetBNController`

新增独立 BN 控制器，负责：

- 在加载检查点后保存所有 BN 层的不可变源 `running_mean/running_var`。
- 按层维护截至上一批的目标均值、方差和累计样本数。
- 在预测阶段安装源统计与历史目标统计的收缩融合结果。
- 在计分后提取当前 batch 统计并更新目标历史。
- 为 Student 和 Teacher 提供相同的只读融合统计，避免两套 BN 状态漂移。

默认融合权重随已见 batch 数从0线性增加，并在5个 batch 后达到上限0.9。目标统计使用按样本数加权的在线合并方差，而不是简单平均 batch 方差。方差必须截断到最小值 `1e-5`，所有写入前检查有限值。

### 4.2 可训练参数

Student 只训练：

- 所有 BN 层的 `weight` 和 `bias`；
- `band_scale`、`band_bias`；
- `warp_ctrl`。

卷积层、bottleneck 的非 BN 参数和 classifier 全部冻结。BN 仿射参数使用目标基础学习率的0.1倍，Adapter 使用1.0倍，Warp 使用0.2倍。Teacher 对上述可训练参数维护 EMA；BN 均值和方差由共享控制器管理，不参加梯度和 EMA。

### 4.3 三阶段启用策略

#### 阶段A：BN warm-up

- 至少持续20个 batch。
- 启用 BN 统计、BN 仿射、Adapter/Warp、可靠性 SEM 和 MT；此阶段的可靠性明确定义为“Teacher 熵置信度 × 标签保持视图一致性”，不包含证据因子。
- 不计算破坏性证据，不写记忆，不启用 PCL/NCL。
- 分类器权重的归一化行向量作为32类只读源锚点，但不伪装成目标记忆样本。

#### 阶段B：证据建库

完成20个 batch 且最近5个 batch 的预测类别覆盖不少于24/32后进入：

- 启用0711显著性证据、可靠性路由和 certain 样本记忆写入。
- 保持 PCL/NCL 关闭。
- 如果覆盖条件未满足，则继续阶段A，不强制切换。

#### 阶段C：完整 EVMT-DtCC

当目标记忆覆盖不少于16个类别，且每个已使用原型至少有2个目标条目时进入：

- certain 样本启用 PCL。
- uncertain 样本在近邻数量充足时启用 NCL。
- 仍未覆盖的类别使用只读源锚点辅助分类多样性，但不能接收目标伪标签权重。
- 若条件在整次运行中始终不满足，方法安全退化为阶段B，而不是强制使用污染记忆。

### 4.4 可靠性与记忆准入

可靠性继续遵循0711：Teacher 熵置信度、标签保持视图一致性和破坏性证据的乘积。进入阶段B后，certain 样本必须同时满足：

- 绝对置信度下限；
- 视图 JS 上限；
- 正 margin drop；
- 类内或全局可靠性阈值。

记忆库只接收通过全部条件的更新前 Teacher 特征。`use_evidence=false` 时必须真正跳过显著性梯度和破坏视图，并使用“置信度＋视图一致性”路由，使消融具有正确语义。

### 4.5 损失与正则

阶段A使用：

`L_A = L_SEM^r + λm L_MT + λreg L_adapter + λwarp L_warp + λbn L_BN-anchor`

阶段B保持相同目标，但启用证据可靠性和记忆写入。阶段C使用完整目标：

`L_C = L_A + λp L_PCL + λn L_NCL`

其中 `L_BN-anchor` 约束 BN 仿射参数不要快速偏离源值，默认 `λbn=1e-3`。Adapter 和 Warp 沿用当前配置中的 `λreg=1e-3`、`λwarp=2e-4`。所有正则均进入实际反向图并写入日志，禁止只存在于配置文件。

### 4.6 塌缩保护

每个 batch 计算预测边际分布、有效类别数 `exp(H(mean_p))`、最大类别占比和最近窗口变化。满足任一灾难条件时跳过梯度、记忆写入和 Teacher EMA，但仍保留已经计分的在线预测：

- logits、loss 或梯度出现 NaN/Inf；
- 有效类别数低于8；
- 最大预测类别占比超过0.5；
- 有效类别数相对最近稳定窗口下降超过50%。

塌缩保护不能读取准确率，也不能回滚到根据目标标签选择的状态。

## 5. 数据流与状态所有权

- `main_tta_evmt.py` 负责配置、检查点、DataLoader 和输出目录。
- `TargetBNController` 独占 BN 源统计、目标历史统计和融合策略。
- `EVMTOnlineRunner` 独占阶段状态、Student/Teacher、优化器、路由器和记忆库。
- `ClassBalancedMemory` 只保存目标 certain 特征；源类锚点由独立只读结构保存。
- 日志器只消费 detached 指标，不能反向影响适配决策。

所有状态在一个任务开始时重置。不同迁移任务和不同随机种子不得共享 BN 历史、记忆或 Teacher 状态。

## 6. 日志与离线诊断

每个 batch 除现有指标外增加：

- 当前阶段、BN目标融合权重、BN历史样本数；
- 预测类别直方图、类别覆盖、有效类别数和最大类别占比；
- 记忆条目数、记忆类别覆盖、每类最小/最大条目数；
- BN/Adapter/Warp 梯度范数与相对源参数位移；
- 各正则损失、跳过原因和有限值状态。

目标标签派生的 certain准确率、uncertain准确率、记忆纯度和 reliability-AUROC 只能在独立离线诊断文件中生成，明确标注“不得被训练读取”。

## 7. 实验顺序与决策规则

在相同检查点、目标顺序、batch size和种子2025下依次运行：

1. Source-only：18.33%现有基线。
2. 当前 Full EVMT：20.72%现有基线。
3. Strict BN-stat：只更新滞后目标统计，不做梯度。
4. BN-affine：BN统计＋BN仿射＋低权重 SEM。
5. BN-MT-Adapter：加入 Adapter/Warp 和多视图 Teacher。
6. BN-first Full：启用状态驱动 Evidence/PCL/NCL。

先在 `0→1` 完成上述矩阵。根据无标签稳定性、类别覆盖、记忆覆盖、有限性和运行成本冻结配置，然后揭示准确率与 macro-F1。配置冻结后以完全相同设置运行 `0→2`。

决策规则：

- Strict BN-stat 若未明显高于 Source-only，停止组合实验并检查严格滞后统计实现。
- Full 若低于 BN-MT-Adapter，优先关闭 PCL/NCL并检查证据正确性相关性和记忆纯度。
- 两个校准任务均稳定且 Full 同时高于 Source-only、当前Full和新的BN基线后，才考虑全部12任务。
- 如果 BN-first 在 `0→1` 仍明显低于离线42.21%诊断上限，再进入源模型重训设计。
- 如果只有转速变化任务表现差，再设计全局频率尺度模块；本轮不提前加入。

## 8. 测试与验收

### 8.1 单元测试

- 当前 batch 统计不会影响当前 batch 的计分 logits。
- 在线均值/方差合并与离线拼接计算一致。
- Student/Teacher 使用相同融合 BN 统计，源统计保持不可变。
- 只有 BN affine、Adapter和Warp具有梯度。
- 三阶段只在规定覆盖条件满足时切换。
- Evidence关闭时不调用显著性计算。
- PCL/NCL在记忆不足时安全返回零。
- 塌缩条件触发时不更新优化器、记忆和EMA。
- 所有新增日志字段可序列化且为有限值。

### 8.2 集成验收

- `0→1` 恰好处理160,299个样本和314个 batch，`passes=1`。
- 所有在线准确率均来自更新前预测。
- 运行无 NaN/Inf，目标样本不重访。
- 输出包含完整配置、检查点哈希、阶段和 BN 状态摘要。
- 结果如实报告，即使没有达到预期也不使用目标标签重新选择阈值或回滚。

## 9. 后续边界

若本设计完成后仍不足，再单独设计并验证两个后续项目：

1. 按 MAT 文件划分源训练/验证、加入全局频率缩放和 Wu 噪声增强的可信源模型重训。
2. 采用全局尺度 `x(f)→x(sf+δ(f))` 的转速感知频率对齐。

二者不得与 BN-first 首轮实验同时引入，以保持因果可解释性。
